Tham chiếu

API Python

Mọi hàm và lớp công khai, nhóm theo module. Phần lớn có thể import thẳng từ pacman_rl; riêng biểu đồ nằm ở pacman_rl.plotting.

Cách import

# nạp lười: `import pacman_rl` không kéo torch, chỉ khi dùng đến tên bên dưới mới nạp module chứa nó
from pacman_rl import (
    PPOConfig, train_ppo, DQNConfig, train_dqn, TrainResult,       # agents
    ActorCriticCNN, QNetwork,                                      # models
    evaluate, watch, run_episodes, random_baseline,                # evaluation
    ppo_policy, dqn_policy,
    save_run, load_run, load_model,                                # runs
    get_device, describe_device, set_seed, moving_avg,             # utils
    make_env, PipelinedEnvs, EpisodicLife, log_reward, count_events, ENV_ID, N_ACTIONS,   # envs
)
from pacman_rl.plotting import plot_training, plot_scores, plot_metric, plot_events, plot_eval

Một "policy" là gì

Ở nhiều chỗ (evaluate, watch) "policy" là một hàm act_fn(obs) -> int, trong đó obs là mảng numpy uint8 hình (4, 84, 84) và kết quả là chỉ số action 0 đến 8. Tự viết hàm như vậy (luật cứng, mạng khác...) là đủ để dùng với mọi hàm đánh giá.

pacman_rl.agents

train_ppo

train_ppo(cfg=None, *, model=None, save_path=None, device=None, render=False,
          watch_every=0, watch_episodes=1) -> TrainResult

Train PPO. Tham số là PPOConfig (siêu tham số) và các tùy chọn chạy:

  • model: ActorCriticCNN có sẵn để train tiếp; None thì tạo mới.
  • save_path: file .pt lưu giữa chừng (mỗi save_every update) và lúc kết thúc.
  • device: torch.device; None thì get_device().
  • render: env số 0 mở cửa sổ, tất cả env chạy tuần tự.
  • watch_every, watch_episodes: cứ mỗi watch_every bước env, mở cửa sổ cho agent chơi watch_episodes ván.

Bắt KeyboardInterrupt: vẫn đóng env, lưu .pt và trả về phần đã train.

train_dqn

train_dqn(cfg=None, *, model=None, save_path=None, device=None, render=False,
          watch_every=0, watch_episodes=1) -> TrainResult

Train DQN, tham số giống train_ppo (với DQNConfig và model là QNetwork). Checkpoint lưu mỗi save_every bước env.

TrainResult

class TrainResult(NamedTuple):
    model: nn.Module     # mạng đã train
    log: dict            # tên chỉ số -> list, cùng độ dài với log["step"]
    episodes: list       # [(bước env, điểm thật của cả ván 3 mạng), ...]

Unpack như tuple được: model, log, episodes = train_ppo(...). Ý nghĩa các khóa trong log ở File lưu và log.

VecFrameReplayBuffer

VecFrameReplayBuffer(capacity, n_envs, device="cpu")
  .add(obs, action, reward, done, is_first)   # mỗi tham số có độ dài n_envs; obs (n_envs,4,84,84)
  .sample(batch_size) -> (s, a, r, s2, done) # tensor trên device
  len(buffer)                                  # số mẫu hiện có

Replay buffer của DQN: lưu frame mới nhất mỗi bước, dựng lại chồng 4 frame khi rút mẫu. Giải thích ở DQN trong pacman_rl.

ALGOS

Dict {"ppo": (PPOConfig, train_ppo), "dqn": (DQNConfig, train_dqn)}. CLI tra cứu thuật toán qua đây; đăng ký thuật toán mới vào đây để dòng lệnh dùng được (xem Thêm thuật toán mới).

pacman_rl.models

ActorCriticCNN

ActorCriticCNN(n_actions)
  .forward(x: uint8 (B,4,84,84)) -> (Categorical, value (B,))
  .act(x)                       -> (action (B,), log_prob (B,), value (B,))   # @no_grad, lấy mẫu Gumbel-max

Mạng của PPO: thân CNN kiểu Nature DQN dùng chung, đầu actor (logit) và đầu critic (giá trị).

QNetwork

QNetwork(n_actions)
  .forward(x: uint8 (B,4,84,84)) -> Q (B, n_actions)
  .head                           # nn.Linear(512, n_actions)

Mạng của DQN: cùng thân CNN, đầu ra là giá trị Q cho từng action.

make_cnn và MODEL_CLASSES

make_cnn() trả về thân CNN (Conv32-8x8/4, Conv64-4x4/2, Conv64-3x3/1, Linear512), dùng chung cho cả hai mạng. MODEL_CLASSES = {"ppo": ActorCriticCNN, "dqn": QNetwork} dùng để nạp lại mạng đúng loại từ tên thuật toán.

pacman_rl.envs

Gói này không import torch (xem Kiến trúc).

make_env

make_env(render_mode=None, episodic_life=False) -> gymnasium.Env

Tạo một env đã tiền xử lý (frame-skip 4, xám, 84x84, noop reset tối đa 30, chồng 4 frame). episodic_life=True chỉ dùng khi học. render_mode="human" để mở cửa sổ.

PipelinedEnvs

PipelinedEnvs(n_envs, n_groups=2, render=False)
  .reset(seed=0)        -> obs (n_envs,4,84,84)
  .send(g, actions)     # gửi action cho nhóm g, trả về ngay (step_async)
  .recv(g)              -> (obs, reward_thật, done, danh_sách_điểm_ván_vừa_kết_thúc)
  .close()
  # thuộc tính: G (số nhóm), gs (env mỗi nhóm), n (tổng env), slices, n_actions, envs

Vector env cho việc học, chia thành n_groups nhóm để chạy xen kẽ với GPU. n_envs phải chia hết cho n_groups. Hai trình train hiện luôn dùng 2 nhóm. Xem Env song song và pipeline.

EpisodicLife

gym.Wrapper: mất mạng thì báo terminated=True; chỉ reset game thật khi hết mạng; ghi info["game_score"] khi hết cả ván.

log_reward, count_events, pop_game_scores

log_reward(r) -> np.ndarray             # log1p(r / 10), float32
count_events(reward) -> (n_pellet, n_ghost)
pop_game_scores(infos) -> list[float]    # điểm các ván vừa kết thúc hẳn, từ info của vector env

Hằng số: ENV_ID, N_ACTIONS (9), OBS_SHAPE ((4,84,84)), PELLET_REWARD (50), GHOST_REWARDS ((200,400,800,1600)). Ý nghĩa ở Môi trường và các loại điểm.

pacman_rl.evaluation

ppo_policy, dqn_policy, random_policy

ppo_policy(model, device, greedy=False)   -> act_fn
dqn_policy(model, device, eps=0.05)       -> act_fn
random_policy(n_actions)                  -> act_fn
  • ppo_policy: greedy=False lấy mẫu từ policy (giống lúc train); greedy=True luôn chọn action xác suất cao nhất.
  • dqn_policy: epsilon-greedy với eps nhỏ để tránh kẹt.

evaluate, watch, run_episodes, random_baseline

evaluate(act_fn, n_episodes=10, max_steps=4500, seed=1000)  -> list[float]
watch(act_fn, episodes=2, max_steps=4500)                   -> list[float]     # mở cửa sổ
run_episodes(act_fn, n_episodes=10, max_steps=4500, seed=None,
             render_mode=None, verbose=False)               -> list[float]
random_baseline(n_episodes=5, n_actions=9)                  -> list[float]
  • Tất cả chạy game đầy đủ 3 mạng và trả về danh sách điểm thật mỗi ván.
  • seed=None: mỗi ván ngẫu nhiên. seed=k: ván thứ i dùng seed k + i.
  • max_steps giới hạn số bước (action) mỗi ván; ván bị cắt vẫn tính điểm đã có.
  • random_baseline không giới hạn bước, seed cố định 0: cho biết "không học gì" đạt bao nhiêu.

pacman_rl.runs

save_run(result, directory, name)            -> (path_model, path_episodes, path_log)
load_run(directory, name, algo, device="cpu") -> TrainResult
load_model(path, algo, device="cpu", n_actions=N_ACTIONS) -> nn.Module  # chế độ eval
run_paths(directory, name)                   -> (path_model, path_episodes, path_log)

algo là "ppo" hoặc "dqn". load_run chấp nhận thiếu file log/episodes (trả về rỗng, chỉ còn model). Định dạng file ở File lưu và log.

pacman_rl.plotting

Mọi hàm nhận runs: dict tên → TrainResult (hoặc tuple (model, log, episodes)), nên vẽ một hay nhiều run đều cùng một cách. Nhiều hàm nhận ax= / axes= để ghép vào figure của bạn.

plot_training(runs, random_scores=None, save_path=None, show=True) -> Figure   # 3 biểu đồ tổng hợp
plot_scores(runs, random_scores=None, w=20, ax=None)     # điểm từng ván + trung bình trượt w ván
plot_metric(runs, key, title=None, ax=None)              # một chỉ số bất kỳ trong log
plot_events(runs, total=None, bin_size=100_000, axes=None)   # viên năng lượng / ma / tỷ lệ
plot_eval(results, save_path=None, show=True) -> Figure   # boxplot điểm đánh giá; in bảng mean/std/max
score_curve(episodes, w=20) -> (steps, avg)               # dữ liệu cho đường trung bình trượt
events_per_bin(log, total=None, bin_size=100_000)        # sự kiện trong mỗi khoảng bin_size bước

pacman_rl.utils

get_device(prefer_cuda=True) -> torch.device    # cuda nếu có; bật TF32 và cuDNN benchmark

moving_avg(x, w) -> np.ndarray                  # trung bình trượt, chế độ "valid"
