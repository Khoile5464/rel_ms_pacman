Tham chiếu

Dòng lệnh (CLI)

Bốn lệnh con: train, eval, play, plot. Chạy được ở thư mục bất kỳ khi môi trường đang bật.

python -m pacman_rl <lệnh> [tùy chọn]
pacman-rl <lệnh> [tùy chọn]          # tương đương
python -m pacman_rl <lệnh> -h        # xem đủ tùy chọn của một lệnh

Quy ước chung: algo là ppo hoặc dqn. Thư mục mặc định cho mọi file là runs/ của thư mục hiện tại. Tên run mặc định là ms_pacman_<algo>.

train

python -m pacman_rl train <algo> [--steps N] [--seed S] [--out DIR] [--name NAME]
                                [--set KEY=VALUE ...] [--render] [--watch-every N]
Tùy chọnMặc địnhÝ nghĩa
algobắt buộcppo hoặc dqn
--steps Ntheo configTổng số bước env. Đè lên total_steps kể cả khi --set total_steps=... cũng có mặt.
--seed S0Seed. Luôn đè lên --set seed=....
--out DIRrunsThư mục lưu kết quả (tự tạo nếu chưa có).
--name NAMEms_pacman_<algo>Tên run; quyết định tên 3 file lưu. Trùng tên là ghi đè.
--set KEY=VALUE ...-Ghi đè siêu tham số, có thể nhiều cặp cách nhau bằng dấu cách.
--rendertắtMở cửa sổ game ở env số 0; tất cả env chạy tuần tự nên rất chậm.
--watch-every N0 (tắt)Cứ mỗi N bước env, mở cửa sổ cho agent chơi 1 ván.

Cú pháp --set

  • Mỗi cặp dạng tên=giá trị, không có dấu cách quanh dấu =.
  • Giá trị được ép kiểu theo kiểu của tham số: trường int nhận cả dạng khoa học (total_steps=2e6, buffer_size=5e5); trường float nhận 1e-4, 0.02.
  • Tên không tồn tại sẽ dừng với thông báo liệt kê các tham số hợp lệ.
  • reward_fn không đặt được từ CLI.
  • Các tham số hợp lệ: xem PPOConfig và DQNConfig. Hai bộ khác nhau, tham số của DQN không dùng được cho PPO và ngược lại.

Ví dụ

python -m pacman_rl train ppo --steps 2000000
python -m pacman_rl train dqn --steps 10000000 --seed 1 --name dqn_seed1
python -m pacman_rl train ppo --set lr=1e-4 n_envs=8 n_steps=256 c2=0.02
python -m pacman_rl train ppo --watch-every 500000

Đầu ra: dòng device: ... | config: {...} (in ra toàn bộ cấu hình thực tế), các dòng log, rồi đường dẫn ba file đã lưu.

eval

Chấm điểm một model đã lưu trên các ván đầy đủ 3 mạng, không mở cửa sổ.

python -m pacman_rl eval <algo> [--dir DIR] [--name NAME] [--episodes N] [--seed S]
                               [--greedy] [--eps E]
Tùy chọnMặc địnhÝ nghĩa
--dir DIRrunsThư mục chứa run.
--name NAMEms_pacman_<algo>Tên run cần nạp (file NAME.pt).
--episodes N10Số ván chấm điểm.
--seed S1000Ván thứ i dùng seed S + i.
--greedytắtChỉ PPO. Chọn action có xác suất cao nhất thay vì lấy mẫu.
--eps E0.05Chỉ DQN. Epsilon khi chơi.
PPO trên 3 ván: mean 453 | std 191 | max 720
Điểm: [280, 360, 720]

play

Mở cửa sổ game để xem model chơi (cần màn hình). Tùy chọn giống eval trừ --seed (không có) và --episodes mặc định 2.

python -m pacman_rl play ppo --greedy --episodes 3
python -m pacman_rl play dqn --name dqn_seed1 --eps 0.01

plot

Vẽ đường học từ các run đã lưu ra file PNG (không mở cửa sổ).

python -m pacman_rl plot <ALGO[:NAME]> ... [--dir DIR] [--out FILE]
Tùy chọnMặc địnhÝ nghĩa
ALGO[:NAME]bắt buộc, một hoặc nhiềuppo hoặc ppo:ten_run. ALGO cho biết loại mạng khi nạp; NAME là tên run (bỏ qua thì dùng ms_pacman_<algo>).
--dir DIRrunsThư mục chứa các run (dùng chung cho mọi run trong lệnh).
--out FILEcurves.pngFile ảnh đầu ra.

Nhãn trong biểu đồ là NAME nếu có, không thì PPO/DQN. Màu cố định chỉ áp dụng cho nhãn PPO/DQN (xanh dương, cam); nhãn khác lấy màu theo thứ tự.

python -m pacman_rl plot ppo dqn --out curves.png
python -m pacman_rl plot ppo:base_s0 ppo:penalty_s0 --out compare.png
python -m pacman_rl plot ppo:ms_pacman_ppo --dir ../notebooks      # nạp từ thư mục khác

Ảnh gồm ba biểu đồ: điểm theo bước, entropy (PPO), và số ma ăn trên mỗi viên năng lượng. Cách đọc ở Vẽ biểu đồ, đọc log.
