pacman_rl

Thư viện huấn luyện PPO và DQN chơi Ms. Pacman (Atari) bằng PyTorch và Gymnasium. Một lệnh để train, một lệnh để chấm điểm, một lệnh để vẽ đường học, và đủ chỗ để bạn thêm thuật toán của riêng mình.

pacman_rl làm được gì

  • Train hai thuật toán chuẩn: PPO (clipped objective + GAE) và DQN gốc (replay buffer + target network). Cả hai dùng chung một thân CNN kiểu Nature DQN.
  • Chạy nhiều env song song: mặc định 16 env, mỗi env một process, chia 2 nhóm chạy xen kẽ với GPU. Chỉ có một policy; các env chỉ là nơi thu dữ liệu. Xem Env song song và pipeline.
  • Chấm điểm công bằng: đánh giá luôn chạy game đầy đủ 3 mạng với seed cố định và cộng điểm thật, không phải reward đã biến đổi.
  • Lưu và so sánh run: mỗi lần train ghi ra model, danh sách ván chơi và log; vẽ nhiều run lên cùng một biểu đồ bằng một lệnh.
  • Dễ mở rộng: thêm thuật toán, chỉ số log, reward hay mạng mới bằng vài file nhỏ, không phải sửa lõi.

Ví dụ nhanh nhất

python -m pacman_rl train ppo --steps 2000000     # lưu vào runs/
python -m pacman_rl eval  ppo --episodes 10       # mean / std / max trên seed cố định
python -m pacman_rl plot  ppo --out curves.png    # vẽ đường học

from pacman_rl import PPOConfig, train_ppo, save_run, get_device

device = get_device()
result = train_ppo(PPOConfig(total_steps=2_000_000), save_path="ms_pacman_ppo.pt", device=device)
save_run(result, ".", "ms_pacman_ppo")     # .pt + _episodes.npy + _log.npy

Bấm tên hàm để mở code

Khi mở docs bằng trình duyệt trực tiếp từ ổ đĩa (file://), mọi tên hàm, lớp, hằng, tham số config và đường dẫn file có dấu ↗ đều là link mở thẳng đúng dòng trong VS Code, ví dụ train_ppo trong trang API. Cần cài VS Code; lần đầu trình duyệt sẽ hỏi cho phép mở ứng dụng. Cách hoạt động và cách cập nhật số dòng ở Quy ước, test, viết docs.

Quy ước đơn vị

Trong toàn bộ tài liệu, một bước (step) là một lần agent chọn action, tương ứng 4 frame game (frame-skip 4). Khi nói "2 triệu bước" nghĩa là 2 triệu action, tức 8 triệu frame. Chi tiết ở Môi trường và các loại điểm.
