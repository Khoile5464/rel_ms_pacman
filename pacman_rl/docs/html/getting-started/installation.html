Cài đặt

Cài đúng thứ tự: môi trường Python, torch bản CUDA, rồi pacman_rl. Làm xong thì chạy ba lệnh kiểm tra ở cuối trang để chắc mọi thứ ổn.

Cố ý. Nếu để pip tự kéo torch, nó sẽ cài bản CPU và đè lên bản CUDA bạn đã cài. Hãy cài torch bản CUDA trước, rồi mới cài pacman_rl.

Các bước cài

  1. Tạo môi trường Python

    Dùng conda (như dự án đang dùng) hoặc venv đều được.

    conda create -n rel_pacman python=3.10
conda activate rel_pacman

    python -m venv .venv
.venv\Scripts\activate

    python3 -m venv .venv
source .venv/bin/activate

  2. Cài torch bản CUDA

    Bản dự án đang dùng là torch 2.3.1 với CUDA 12.1:

    pip install torch==2.3.1 --index-url https://download.pytorch.org/whl/cu121

    Máy không có GPU NVIDIA thì cài bản CPU: pip install torch==2.3.1.

  3. Cài pacman_rl

    Chạy từ thư mục rel_ms_pacman/ (thư mục chứa pacman_rl/):

    pip install -e pacman_rl

    Cờ -e (editable) nghĩa là sửa code trong src/ có hiệu lực ngay, không cần cài lại. Muốn chạy test thì cài kèm pytest: pip install -e "pacman_rl[dev]".

    Môi trường đã có đủ thư viện?

    Thêm --no-deps để pip không đụng tới các gói đã cài: pip install -e pacman_rl --no-deps. Đây là cách README dùng với env rel_pacman có sẵn.

Kiểm tra cài đặt

Chạy lần lượt ba lệnh. Mỗi lệnh kiểm tra một tầng khác nhau.

1. Import được thư viện

python -c "import pacman_rl; print(pacman_rl.__version__)"

0.1.0

2. Nhận đúng thiết bị tính toán

python -c "from pacman_rl import get_device, describe_device; print(describe_device(get_device()))"

cuda | NVIDIA GeForce RTX 3070 Ti Laptop GPU

Nếu in cpu | CPU trong khi máy có GPU, torch bạn cài là bản CPU. Cài lại theo bước 2.

3. Emulator và ROM hoạt động

python -c "from pacman_rl.envs import make_env; e = make_env(); obs, _ = e.reset(seed=0); print(obs.shape, obs.dtype)"

A.L.E: Arcade Learning Environment (version 0.10.2+c9d4b19)
[Powered by Stella]
(4, 84, 84) uint8

Hai dòng A.L.E ... và [Powered by Stella] là thông báo bình thường của emulator. Khi train với 16 env bạn sẽ thấy chúng lặp lại nhiều lần, mỗi process con in một lần.

Trên Windows, script riêng cần if __name__ == "__main__"

Env song song dùng multiprocessing kiểu spawn: process con import lại file chính. Nếu bạn viết file .py gọi train_ppo(...), hãy đặt lệnh gọi trong khối if __name__ == "__main__":, nếu không process con sẽ chạy lại cả script. Dòng lệnh python -m pacman_rl ... và notebook đã được xử lý sẵn. Xem thêm Xử lý sự cố.

Lệnh pacman-rl

Cài xong còn có lệnh pacman-rl (nằm trong Scripts/ của môi trường), tương đương với python -m pacman_rl. Hai dạng sau chạy y hệt nhau:

pacman-rl train ppo --steps 100000
python -m pacman_rl train ppo --steps 100000
